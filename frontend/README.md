# Second Chance Frontend

Polished React 18 + Vite frontend for Second Chance, a financial-aid research tool for international students applying to US universities.

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

The frontend will run at `http://127.0.0.1:5173/` and proxies `/api` calls to the FastAPI backend at `http://127.0.0.1:8000/`.

## Production Build

```bash
npm run build
```
